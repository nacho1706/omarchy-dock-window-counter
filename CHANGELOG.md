# Changelog

## 1.1.0 — 2026-11-10

- Rebuilt as an independent, click-through indicator overlay over the existing native dock.
- Removed all adapters, cross-plugin imports, dock replacement behavior, and third-party plugin modifications.
- Both the counter and the separate dock provider can remain enabled.
- Kept workspace-local dots, exact count badges, minimized-origin metadata and terminal app grouping.
- Documented native-geometry and autohide visibility limits.

## 1.0.3 — 2026-11-10

Renamed to Dock Window Counter and updated repository and marketplace metadata.

## 1.0.2 — 2026-11-10

Initial public release. Superseded by the independent overlay in 1.1.0.
