# Changelog

## 1.0.2 — 2026-11-10

Initial public release.

- Outlined running dots and contrasting duplicate-window badges in the native floating dock.
- Counts follow the active workspace on each monitor, including minimized-window origins.
- Omarchy agent terminals group with the configured terminal app.
- Stock Omarchy dock replacement and optional backed-up Genie 0.2.4 adapter.
- Root manifest, screenshot preview, MIT license and preserved upstream dock attribution.
- Automated release-structure checks, seven model tests and three adapter safety tests.

See VERIFICATION.md for live coverage and known testing limits.
